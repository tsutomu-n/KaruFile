写真や資料を、送る・共有する前に

KaruFileで何ができるの？

KaruFileは、写真やPDF、指定したExcel、対応する動画から、容量を抑えたコピーを作る道具です。

メールで送ったり、共有フォルダーに置いたりする前の準備に使えます。
元の資料はそのまま残ります。

原本を残して、配布用のコピーを用意する。

  2. 02元の資料と、できあがった資料

01こんなときに使えます

身近な仕事の例
仕事でよくある困りごとKaruFileでできること
現場写真が何十枚もあり、
容量が大きい		フォルダー内の写真をまとめて、縮小・圧縮したコピーを作ります。
会議資料のPDFを配布したい文字だけのPDFを調べ、小さくできるものを軽量化します。
紙をスキャンした報告書が大きい文章の資料と確認して対象に指定すると、白黒の軽いコピーを作れる場合があります。
図面や写真の細部を変えたくない図・写真入りPDFは、通常は加工せず、そのままコピーします。

小さくなるかどうかは資料によります。必ず軽くなる、メールで送れる容量に収まる、という保証はありません。

写真などの画像ファイルはJPEG形式で出力します。透明部分は白くなります。複数ページ画像や動く画像は、先頭の1枚だけが出力されます。

02元の資料と、できあがった資料

架空の「会議資料」フォルダーを、通常設定で処理する例です。
元の資料は変更・削除せず、別のフォルダーに結果を作ります。

出力先は別の場所です

保存先を指定しない場合は、元のフォルダーと同じ階層に「会議資料_軽量化」を使います。中のフォルダー構成も引き継ぎます。

そのままのPDFもあります

加工しない方針のPDFや、小さくできないPDFは原本をコピーします。容量が変わらないこと自体は、失敗ではありません。

フォルダー全部のバックアップを作る道具ではありません。
Wordや選択していないExcelなど、処理対象でないファイルはコピーされません。既定のstandardでは動画も出力されません。動画は第4節、Excelは第5節の追加指定で処理します。

図は処理結果の例です。エラーが出た場合は、出力ファイルがあっても、実行結果を確認してください。

03PDFをもっと軽くしたいとき

文字データのない画像PDFが自動対象です。写真だけのPDFも含み、色は失われます。OCR文字付きや文字・図形の混在は既存の指定を使います。PDF1冊も入力へ直接指定できます。

文字の形を変えてよければ、字体を統一できます

たとえば、明朝体の報告書をゴシック体にして配布できる場合です。PDF内の字体のデータが大きい資料では、容量を減らせる場合があります。追加指定すると、日本語・英語の横書きを、Windows 11の「メイリオ（標準の太さ）」へ統一する候補を作ります。対象PDFの指定は必要ですが、字体名の指定は不要です。追加指定で「游ゴシック」も選べます。通常のPDF圧縮では字体を変えません。

文字の形や太字の強調が変わり、検索・コピー時の空白が変わる場合があります。スキャン画像の中の文字には、この字体統一は効きません。対応できないPDFや、小さくならないPDFでは、字体を変えない結果になることもあります。元のPDFは残ります。

タグ付きPDFや透過ロゴ入りでも、対応する構造なら試せます。游ゴシックにない「☑」はメイリオで処理できる場合があります。選んだ字体にない文字や注釈内の文字があるPDFは、そのまま残ります。最初は1冊を別フォルダーで試し、できあがりを確認してください。操作は末尾の「字体を統一する手順」を参照します。

04動画を軽くする・音声を消す

現場の様子や作業手順を撮った動画を、共有前に軽くする用途にも使えます。元動画は残し、別フォルダーに結果を作ります。

既定の standard は動画を処理しません。動画を処理するには compact を選びます。初回は動画用の道具（FFmpeg・ffprobe）の準備も必要です。

  • 説明の声を残して、動画を軽くしたい

    --preset compact
    映像と音声を圧縮します。音声は自動では消しません。

  • 会話や周囲の音を消して、動画を軽くしたい

    --preset compact に --video-remove-audio を追加します。成功した出力には音声が入りません。

  • 従来の厳しい形式判定を使いたい

    --video-safe を追加します。通常は付けません。撮影方式などの情報が不足した動画や、フレーム間隔が変わる動画を除外します。

上の指定はコマンドに付けるオプションです。音声除去と厳格判定は併用できます。入力・保存先を含む実行例は、末尾の「動画を圧縮・無音化する手順」で確認してください。

音声除去に失敗したら、音声付きコピーでは代用しません。
未対応の動画や、画質・容量の条件を満たせない動画はエラーになります。以前の出力が残る場合もあるため、ファイルがあるだけで成功と判断しないでください。

HDR・字幕付きなど、まだ変換できない動画もあります。細部や動きは変わる場合があります。縦1080×1920の動画は404×720へ縮小されます。音声除去は、映像に写った顔や文字を消す機能ではありません。

compactは同じフォルダー内のPDF・写真も処理します。動画だけを処理したい場合は、対象の動画だけを入れたフォルダーを指定します。原本保護・保存先の検査・変換後の検証は常に有効です。

05Excelの中の写真を軽くする

写真をたくさん貼った報告書や台帳で、画像が表示サイズより大きすぎる場合に使います。対象のExcel（.xlsx）を追加指定すると、画像の余分な画素数を減らしたコピーを作ります。通常はOFFで、元のExcelは残します。

--excel-pattern "写真台帳/*.xlsx"で対象を選びます。初回はExcel用の道具の準備が必要です。両presetとも既定は長辺800px・JPEG品質72です。小さいJPEGも再圧縮するため画質は劣化します。

シート上の画像の大きさとトリミングは変えず、PNGの透明部分も維持します。数式や書式など、画像以外の内部データが変わっていないことを確認してから出力します。

初版では、縮小できない画像もあります。
行や列のサイズ、字体などから表示サイズを確定できない配置では、その画像を変更しません。他の対応画像は処理できます。セル内画像・マクロ・署名付きなどはブック全体をそのままコピーします。古い.xls形式は対象外です。

まず1冊で試し、Excelで開けること、写真内の小さい文字・数式・印刷結果を原本と見比べてください。表示や印刷をExcel自身で自動確認する機能はありません。縮小できなかった場合とエラーはレポートで区別できます。

エラー時には新しいExcelコピーを作らず、以前の出力が残る場合があります。ファイルがあるだけで成功と判断しないでください。準備とコマンドは、末尾の「Excelの画像を縮小する手順」を参照してください。

06ここだけは知っておいてください

  • 文章PDFが白黒になる場合があります。

    色分けした文字など、仕事に必要な色が残っているか見比べてください。

  • 写真を小さくすると、細部が見えにくくなる場合があります。

    写真内の小さな文字や細い線を確認してください。小さい写真を鮮明にする機能ではありません。

  • 「写真ファイル」と「写真入りPDF」は扱いが違います。

    写真ファイルは縮小・圧縮します。写真入りPDFは、通常は加工せずコピーします。

  • 読めない文字を読み取ったり、個人情報を消したりする機能はありません。

    写真の位置情報などが残る場合もあります。共有前の情報確認は別途必要です。

  • 動画は、共有先で映像と音を確認してください。

    音声を残す指定なら必要な声が聞こえるか、除去する指定なら音が出ないかを確認します。出力のAV1形式に対応しない再生ソフトでは開けない場合があります。

07できあがったら、ここを確認

メールに添付したり、共有フォルダーへ置いたりする前に、原本と結果を見比べます。

  1. 文字や数字が読めるか

    日付・金額・寸法や、小さな文字を確認します。字体を統一した場合は、太字の強調と、普段使うPDF閲覧ソフトでの検索・コピーも確認します。

  2. 必要な色・細部・音声が意図どおりか

    色分けや写真の線・傷・黒板の文字を確認します。動画は最初から最後まで再生し、映像の向き・動きと、音声が指定どおりに残る／消えることを確認します。

  3. エラーが出ていないか

    実行画面のエラー表示とレポートを確認します。ファイルができていても、エラーが残っている場合があります。

PDFは、原本と結果を並べる比較画面も作れます

追加設定の --pdf-preview を付けると、原本と実際のできあがりを同じ倍率で見比べる画面を作れます。通常は作成しません。

比較画面は1冊100ページまでです。字体統一は200ページまで試せますが、101ページ以上では比較画面を作れません。比較側のエラーが出ても、完成したPDFは残ります。

比較画面はブラウザーで開けます。持ち運ぶときは、画像やPDFを含む比較用フォルダー全体をまとめてください。

実際の操作は、PowerShellから行います

PowerShellという画面にコマンドを入力して使います。初回の準備、対象の指定、実行、エラーの確認は、既存の利用者マニュアルに沿って進めてください。

利用者マニュアルを読む 字体を統一する手順 PDFの比較画面について エラーの確認方法 動画を圧縮・無音化する手順 Excelの画像を縮小する手順

このガイドだけを受け取った場合は、KaruFile一式にある MANUAL.md を確認してください。上のリンクは、リポジトリ内の配置で開くためのものです。
