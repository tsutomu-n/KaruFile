写真や資料を、送る・共有する前に

KaruFileで何ができるの？

KaruFileは、写真やPDFから、容量を抑えたコピーを作る道具です。

メールで送ったり、共有フォルダーに置いたりする前の準備に使えます。
元の資料はそのまま残ります。

原本を残して、配布用のコピーを用意する。

このガイドで分かること

  1. 01こんなときに使えます
  2. 02元の資料と、できあがった資料
  3. 03ここだけは知っておいてください
  4. 04できあがったら、ここを確認

01こんなときに使えます

身近な仕事の例
仕事でよくある困りごとKaruFileでできること
現場写真が何十枚もあり、
容量が大きい		フォルダー内の写真をまとめて、縮小・圧縮したコピーを作ります。
会議資料のPDFを配布したい文字だけのPDFを調べ、小さくできるものを軽量化します。
紙をスキャンした報告書が大きい文章の資料と確認して対象に指定すると、白黒の軽いコピーを作れる場合があります。
図面や写真の細部を変えたくない図・写真入りPDFは、通常は加工せず、そのままコピーします。

小さくなるかどうかは資料によります。必ず軽くなる、メールで送れる容量に収まる、という保証はありません。

写真などの画像ファイルはJPEG形式で出力します。透明部分は白くなります。複数ページ画像や動く画像は、先頭の1枚だけが出力されます。

02元の資料と、できあがった資料

架空の「会議資料」フォルダーを、通常設定で処理する例です。
元の資料は変更・削除せず、別のフォルダーに結果を作ります。

出力先は別の場所です

保存先を指定しない場合は、元のフォルダーと同じ階層に「会議資料_軽量化」を使います。中のフォルダー構成も引き継ぎます。

そのままのPDFもあります

加工しない方針のPDFや、小さくできないPDFは原本をコピーします。容量が変わらないこと自体は、失敗ではありません。

フォルダー全部のバックアップを作る道具ではありません。
Word・Excelなど、処理対象でないファイルはコピーされません。通常設定では動画も出力されません。必要な資料がすべてそろうとは限りません。

図は処理結果の例です。エラーが出た場合は、出力ファイルがあっても、実行結果を確認してください。

文章のスキャンと確認して指定すると、白黒の軽いコピーを作れる場合があります。指定しても、構造や確認結果によっては原本をコピーします。罫線のある表も通常は保護され、加工には内容の確認と指定が必要です。

03ここだけは知っておいてください

  • 文章PDFが白黒になる場合があります。

    色分けした文字など、仕事に必要な色が残っているか見比べてください。

  • 写真を小さくすると、細部が見えにくくなる場合があります。

    写真内の小さな文字や細い線を確認してください。小さい写真を鮮明にする機能ではありません。

  • 「写真ファイル」と「写真入りPDF」は扱いが違います。

    写真ファイルは縮小・圧縮します。写真入りPDFは、通常は加工せずコピーします。

  • 読めない文字を読み取ったり、個人情報を消したりする機能はありません。

    写真の位置情報などが残る場合もあります。共有前の情報確認は別途必要です。

  • 動画は通常設定では処理・コピーしません。

    動画も追加設定で処理できます。別の準備が必要なので、詳しくはマニュアルを確認してください。

04できあがったら、ここを確認

メールに添付したり、共有フォルダーへ置いたりする前に、原本と結果を見比べます。

  1. 文字や数字が読めるか

    日付・金額・寸法や、スキャンした小さな文字を確認します。

  2. 必要な色や写真の細部が残っているか

    色分けの意味や、写真の線・傷・黒板の文字などを確認します。

  3. エラーが出ていないか

    実行画面のエラー表示とレポートを確認します。ファイルができていても、エラーが残っている場合があります。

PDFは、原本と結果を並べる比較画面も作れます

追加設定の --pdf-preview を付けると、原本と実際のできあがりを同じ倍率で見比べる画面を作れます。通常は作成しません。

比較画面はブラウザーで開けます。持ち運ぶときは、画像やPDFを含む比較用フォルダー全体をまとめてください。

実際の操作は、PowerShellから行います

PowerShellという画面にコマンドを入力して使います。初回の準備、対象の指定、実行、エラーの確認は、既存の利用者マニュアルに沿って進めてください。
